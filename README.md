# OJT Weekly Report and DTR Monitoring System

This repository contains the OJT-DTR system and its documents.

The system lets OJT trainees record their daily time record (DTR) and write weekly reports. Facilitators monitor and approve the records of their OJTs. Admins manage users, companies, and batches.
